# 沖ドキ！GOLD / GOLD-30 期待値・天国間G数ツール

GitHub Pagesで動く、サーバー不要のブラウザツールです。

- 古い順に当選G数とBB/RBを入力すると、前回ボーナス終了時の天国間G数Cを計算します。
- C・貸出枚数・交換枚数から、事前計算済み期待値表を内挿表示します。
- 履歴はページのメモリ内だけに保持し、サーバーへ送信しません。再読み込みで消えます。
- 通常時32G/50枚、BB210枚・69G、RB90枚・29G。所要時間は750G/時です。
- 交換枚数は、1000円あたりの貸出枚数以上を指定してください。

## 重要な前提

基準条件「天国抜けC=0・当該32Gから、次の天国または初回2000G以上当選後の非天国まで」の機械割を、ユーザー指定の96%に合わせた推定モデルです。実証された理論値、勝利保証、観測バイアスの完全な除去を意味しません。

Cは実機内部の有利区間カウンターそのものではありません。32G以内の連続当選を天国とみなした履歴上のカウンターです。

公開データは2026-10-07〜19および28の保存済みデータから作成した、集計済み平均値のみです。元の台別SQL・履歴原本・認証情報・収集機能は含みません。追加収集や再学習を行わず、全計算をブラウザ内で実行します。
